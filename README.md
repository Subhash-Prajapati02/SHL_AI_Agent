# SHL AI Assessment Recommender

Beginner-friendly RAG-based conversational recommendation system built using:

- FastAPI
- Agno
- Groq
- ChromaDB
- Sentence Transformers

---

# Features

- SHL-only recommendations
- Semantic search
- Conversational RAG
- JSON catalog ingestion
- Markdown conversation traces
- ChromaDB vector storage

---

# Run

```bash
uvicorn app:app --reload
```
